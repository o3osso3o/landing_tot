# Track on your Track Landing Page

걷기 전용 스트리밍 앱 `Track on your Track`의 UI/UX 포트폴리오 랜딩페이지입니다.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

GitHub Pages deployment runs automatically on every push to `main`.

Production URL:

https://o3osso3o.github.io/landing_tot/

## Images

이미지 경로는 `src/App.jsx`의 `STREAMING_IMAGE_PATHS`에서 관리합니다.
실제 이미지는 `public/assets`에 추가한 뒤 경로만 교체하면 됩니다.

## Prototype

Figma 프로토타입 링크는 `src/App.jsx`의 `FIGMA_PROTOTYPE_URL`에서 관리합니다.
